# Handoffs

Passagem de bastão entre agentes do squad. Um arquivo por handoff:
`AAAA-MM-DD-<de>-para-<para>.md` (ex.: `2026-10-08-node-runner-para-scalpel.md`). Mais de um
no mesmo dia entre o mesmo par ganha sufixo `-2`, `-3`. O painel War Room desenha a linha
do handoff a partir do nome, então o padrão precisa ser exato.

Seções: **Entregue** (arquivos tocados, ADRs que governam a tarefa), **O que falta**
(passos concretos) e **Riscos** (o que quase deu errado). Sem código colado: referencie
`arquivo:linha`.
